## A. Cari tahu JASA
- **Apa itu JASA** — platform berbagi langganan ala carpooling: *host* (pemilik langganan) menawarkan slot kosong, *joiner* bergabung dan
  membagi biaya; JASA mengamankan transaksi. Plus grup Resmi JASA, jasa bayar, marketplace.
- **Kenapa murah** — biaya plan resmi dibagi rata ke slot; harga mengikuti tarif resmi Indonesia sehingga adil antaranggota.
- **Legal?** — hanya plan yang mengizinkan banyak pengguna/layar; pengguna wajib patuh ToS layanan (`06-legal-risiko.md`).
- **Pembayaran aman?** — lewat payment gateway berizin BI (Xendit/Tripay), puluhan metode bayar.
- **Data pribadi** — dikelola sesuai UU PDP & UU ITE (`17-kebijakan-privasi.md`). **S&K** — `04-rules-syarat-ketentuan.md`.

## B. Panduan pengguna (akun)
- **Daftar** — via Google / email (per 31 Okt 2026 Facebook & X tidak tampil lagi, `24` §2.5); daftar email → kode aktivasi dikirim ke email.
- **Satu orang satu akun** — akun ganda dilarang (keamanan & keunikan data).
- **Lupa password** — Login → Lupa Kata Sandi → tautan reset ke email. Lupa email terdaftar → hubungi CS.
- **Ganti email** — tidak bisa sendiri; pulihkan akses email dulu; jalan terakhir CS mengganti setelah verifikasi.
- **Verifikasi nomor HP** — wajib untuk host (konfirmasi nomor aktif & kontak penyelesaian masalah).
- **Pemeriksaan profil (KYC)** — dukungan pencegahan TPPU/TPPT: unggah salah satu KTP / paspor / izin tinggal / SIM; diverifikasi ≤ 72 jam.
  Ditolak → lihat alasan di riwayat dokumen, unggah ulang tanpa mengulang kesalahan.
- **Skor kepercayaan 0–100** — tampil di foto profil; naik dengan foto profil, verifikasi email/HP, KYC, unggah faktur. Skor tinggi = penawaran lebih sering tampil.
- **Privasi kontak** — sesama anggota grup melihat nama/alias, foto, nomor HP (bisa disembunyikan lewat toggle); email di chat grup disembunyikan.
- **Hapus akun** — Informasi Pribadi → Hapus Akun; semua langganan berhenti, data dihapus permanen, tanpa refund. Hapus langganan dulu.
- **Kontak** — live chat, email, WhatsApp; jam layanan di `05-sop-admin.md`.

## C. Gabung langganan (joiner)
- **Cara gabung** — Jelajahi → pilih layanan → pilih penawaran → Gabung → centang S&K → bayar → cek kredensial/undangan.
- **Penerimaan instan** — aktif: langsung bergabung setelah bayar. Nonaktif: bayar di muka pakai **dompet**, saldo dipotong saat host menerima;
  host wajib menjawab ≤ 48 jam. Joiner bisa **batal** setelah 2 menit selama host belum menerima → dana kembali ke dompet.
- **Kapan ditagih** — saat pertama bergabung dan saat perpanjangan berikutnya.
- **Akses langganan** — Dashboard → Akses Langganan → "Tampilkan Kredensial" (akun bersama) atau Lihat Undangan (family/tim).
- **Berhenti** — kapan saja (tidak mengikat): Akses Langganan → Tinggalkan [layanan] → Konfirmasi. Refund mengikuti aturan §F.
- **Tidak ada penawaran** — jadi host sendiri, atau klik **Gabung Daftar Tunggu** → notifikasi email + WhatsApp saat ada host baru.
- **Beda harga untuk layanan sama** — tergantung periode tagihan host (bulanan/tahunan), tarif lama/baru, dan jenis paket.
- **Langganan hilang dari dashboard** — dihapus host (berhenti bayar/berhenti berbagi) atau dihapus JASA karena melanggar.
- **Kode etik joiner** — hormati langganan host (jangan ubah apa pun selain profil sendiri); slot hanya untuk diri sendiri, dilarang membagikan login;
  sopan & sabar.

## D. Berbagi langganan (host)
- **Cara berbagi** — Tambah Langganan Baru → pilih layanan → jumlah slot dibagikan → harga (dihitung otomatis dari tarif resmi) → publik/pribadi →
  penerimaan instan on/off → kredensial atau metode undangan.
- **Layanan belum terdaftar** — buat *custom sharing* (pribadi), ditinjau admin.
- **Publik vs pribadi** — publik tampil di marketplace untuk semua joiner; pribadi hanya lewat tautan undangan (keluarga/teman) dan
  **tanpa connection fee**. Bisa diubah kapan saja. Tautan undangan juga tersedia untuk publik.
- **Slot sudah terisi sendiri** — host bebas menyisakan slot pribadi; hanya slot yang dibagikan yang dibayar joiner.
- **Pendapatan host** — harga slot penuh; bulan pertama tiap joiner baru dipotong connection fee (`19-pendapatan.md`). Joiner keluar di tengah
  periode → host tetap menerima pembayaran penuh bulan itu; slot kembali tersedia (publik otomatis di marketplace).
- **Joiner keluar & akun bersama** — ganti password lalu perbarui di Kelola Langganan; skema undangan → keluarkan akun joiner dari family.
- **Ganti kredensial** — Kelola Langganan → Kredensial → Ganti; joiner otomatis diberi tahu.
- **Berhenti berbagi / hapus langganan** — Kelola Langganan → Hapus Pembagian Saya → Konfirmasi.
- **Faktur pembelian** — opsional, menaikkan skor kepercayaan & badge "faktur terverifikasi"; tidak terlihat pengguna lain.
- **Aman berbagi kredensial?** — gunakan password unik per layanan, PIN profil, verifikasi perubahan email/password di sisi layanan.
- **Kode etik host** — (1) pemilik sah langganan, siap menunjukkan faktur; (2) penawaran identik dengan paket asli; (3) langganan Indonesia & tarif resmi,
  **tidak boleh mengambil untung**; (4) layanan minimal 30 hari per joiner; menghentikan tanpa pemberitahuan = pembayaran bulan berjalan dibatalkan;
  (5) masa promo/uji coba boleh asal diperpanjang; mengganti login berkala = akun ditangguhkan.
- **Harga layanan naik** — host tidak perlu apa-apa; sistem menyesuaikan harga penawaran untuk periode berikutnya dan memberi tahu joiner.

## E. Kelola pembayaran
- **Metode** — QRIS, VA bank (BCA, BNI, BRI, Mandiri, Permata, BSI, CIMB, BJB, Sahabat Sampoerna), e-wallet (DANA, OVO, ShopeePay, LinkAja), Indomaret/Alfamart,
  **tanpa kartu kredit/debit** (keputusan pemilik 31 Okt; daftar resmi `config/pembayaran.json`),
  dan **Dompet JASA**. Pembayaran berulang diingatkan otomatis oleh gateway.
- **Dompet** — isi ulang min Rp50.000 (Dompet Saya / Metode Pembayaran → Isi Dompet). Saldo **tidak bisa ditarik** ke bank/e-wallet, **tidak kedaluwarsa**,
  hanya untuk bayar patungan & marketplace. Sumber saldo: top-up, refund, reward referral, komisi afiliasi. Opsi "Pakai saldo otomatis saat checkout".
- **Rekening bank (host/seller)** — hanya **satu** rekening; tambah di Informasi Pribadi → Akun Bank (bukti kepemilikan, nama bank, nomor rekening),
  verifikasi ≤ 72 jam; ganti rekening → verifikasi ulang sebelum penarikan. Ditolak → lihat alasan, unggah ulang.
- **Kode voucher** — dua jenis: **kode promo** (diskon/saldo gratis dari JASA) dan **kode referral** (milik tiap pengguna). Masukkan di menu Reward & Bonus → Periksa Kode.
- **Referral** — setiap kode yang diaktifkan pengguna baru = saldo Rp10.000 ke dompet pemilik kode; bagikan lewat salin kode, tautan, Facebook, X.

## F. Penyelesaian masalah
- **Refund boleh bila**: akses hilang & host tidak memberi kabar (kredensial diubah, langganan dibatalkan); penawaran tidak sesuai (negara beda,
  jumlah layar beda, slot tidak ada); dikeluarkan host tanpa alasan sah.
- **Refund tidak bisa bila**: keluar sendiri sebelum periode habis; layanan tidak sesuai harapan (katalog, coba-coba); grup **pribadi**.
- **Cara minta refund** — Informasi Pribadi → Pengembalian Dana, atau dari halaman langganan (⋮ → Pengembalian Dana): baca syarat → pilih langganan,
  alasan, screenshot, penjelasan → Kirim. Diproses ≤ 48 jam; dana ke **dompet**. Ditolak → alasan dijelaskan.
- **Kredensial tidak berfungsi** — di halaman langganan jawab "Apakah kredensial berfungsi?" → ✗ (host diberi tahu) → chat host → hubungi CS →
  tidak selesai: refund diproses ≤ 72 jam.
- **Host tidak merespons** — permintaan bergabung: host maks 48 jam, lewat itu hubungi CS; chat grup tak dibalas → host juga dapat email; boleh WA/telepon
  host jika ia mencantumkan nomor; eskalasi ke CS.
- **Penawaran tidak sesuai** (mis. dijanjikan Premium ternyata Standard) — diskusikan di chat grup; tidak berubah → ajukan refund; host skor 100 /
  faktur terverifikasi dijamin sesuai iklan.
- **Joiner berhenti sebelum akhir bulan** (sisi host) — pembayaran di muka, host tetap menerima penuh.
